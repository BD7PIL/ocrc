# 0.17.0 桌面体验批次：上下文环 + 右栏工作台 + 流式对齐 opencode web

## M3 流式改造（先做——卡片契约改动最大）
1. **交错顺序**：`web/src/lib/components/CardStreaming.svelte` 改为按 blocks 原序渲染（text 段 → `MarkdownView` streaming 模式；tool 段 → `ToolCallList` 原位分组），废除"tools 置顶、text 垫底"；ToolCallList 的 LIMIT 12 改按全局索引截断。
2. **贴底哨兵**：`web/src/routes/[sessionId]/+page.svelte` 的 `.stream` 末尾加哨兵元素 + ResizeObserver——内容长高即使无新卡也保持贴底（现有 pinnedToBottom 契约不变，onDestroy 断开）。
3. **推理实时流**（已批）：
   - 后端：`src/core/stream-accumulator.ts` 的 reasoning block 透传进 streaming 卡（`src/core/structured-card.ts` 公共 ContentBlock 扩 `reasoning` 类型，仅 streaming 卡携带）；relay finalize 时 final assistant 卡新增 `thinkingText` 字段携带本轮完整推理文本（非 block）。
   - 前端：CardStreaming 按原序渲染 reasoning 段=折叠一行"思考中"+脉冲点，点开看实时推理纯文本；CardAssistant 顶部按 thinkingText 渲染默认折叠的思考块；CardThinkStream 退役。
   - 隔离：TG renderer 现有"过滤 reasoning"逻辑保留、忽略 thinkingText 字段——TG 渲染零变化。
   - 测试：relay/stream-accumulator 补 reasoning 契约用例（streaming 带、final thinkingText、完成卡无 reasoning block）。

## M1 上下文环（ZCode 式 hover）
- 新组件 `web/src/lib/components/ContextRing.svelte`：24px SVG 环 + mono 百分比，放 Composer footer 左簇末尾（SessionControls 后、spacer 前），仅桌面显示。
- 弧色语义化（非交互不橙）：<70% `--ok` / 70–90% `--warn` / >90% `--err`。
- 数据 = `api.context(sessionId)`，feeds lastSeq → 1s 防抖重取（Inspector 同款 pattern）。
- hover/点击弹面板（复用 chips 的 .wrap/.pop 模式，上弹、z-popover、Esc+外点关）：已用/上限 + **堆叠容量条**（缓存读/缓存写/输入/输出四段真实数据）+ 缓存命中率 + 模型 + 成本 + 消息数（feed 计数）。**不做 ZCode 的引擎级分类明细**（消息/技能/MCP 占比——opencode 不暴露，不造假数据）。
- Inspector 上下文 tab（ContextSpecPanel）保留为深度面板。

## M2 右栏工作台
- **文件 tab → 双栏查看器**（FilesPanel 重构）：左目录列表（现 browse API + 面包屑/上级），右常驻查看区（不再 800 字符模态）：全量拉取、200KB 截断提示条、.md 用 MarkdownView 渲染（高亮/Copy 复用）、其余文本走代码块高亮路径；面板 <420px 退化回模态。
- **新增 子代理 tab**（SubagentsPanel）：Inspector TABS 加"子代理"；api.subagents + tick 防抖（client.ts 的 SubagentRow 补漏掉的 busy 字段）；运行中排前。点行 → 右栏**内嵌实况**轻 transcript（api.history limit 40：user 行 + assistant 段 MarkdownView + tool 摘要行），tick 只刷新当前打开的子会话；顶部"← 返回"与"打开会话"（PlanHud 跳转语义不变）。
- Tab 栏配 Icon.svelte 图标，视觉对齐 ZCode。
