# 逐组件视觉 / 动线评审

这张表就是"看过每个组件"的定义：**组件 × 状态**，每项一张截图。`scripts/audit.mjs`
按它驱动预览（真面板 + 真 kit + 假宿主），把图写到本目录。

```bash
node extensions/ocrc/scripts/audit.mjs            # 全套 24 张
node extensions/ocrc/scripts/audit.mjs --only 15  # 只跑序号含 15 的项
node extensions/ocrc/scripts/audit.mjs --no-serve # 复用已在跑的预览
```

每张图看七件事：**层次**（谁先说）、**对齐**（网格/列宽）、**折行**（长文本不裁切）、
**裁切**（不溢出）、**对比度**（深色也算）、**术语**（上游词，不夹内部机制）、
**动线**（下一步看得出来吗、破坏性动作有守卫吗、错误贴在哪）。

## 这一轮（第一遍）抓到并修掉的

| 级别 | 问题 | 证据 | 修法 |
| --- | --- | --- | --- |
| P0 | 服务不可达时同时显示错误横幅与「还没有服务器」空态（请求失败了却断言"没有"） | 03 第一遍 | 空态条件加 `!error && !loading`；计数改说「列表读取失败」 |
| P0 | 配对链接 / ssh 命令行被裁切 | 实测 `scrollWidth 754 vs 572`、`766 vs 572` | `.oc-pre` 改 `pre-wrap` + `overflow-wrap: anywhere` |
| P0 | 首屏会报「宿主桥未就绪」：RemoteInstance 第一遍渲染时 host 还是 null | 02 第一遍 | 面板在 host 就绪前不发请求，自己说「正在连接宿主…」；组件的 effect 也加 host 守卫 |
| P1 | 检查结果卡里 `KitList` 的 64px `row-lead` 列让候选/动作清单像坏表格 | 13 第一遍 | 换成普通行（`· 版本 · 路径`、`! FAIL …` 红字） |
| P1 | 「兼容档：旧档（glibc 2.17…）（按 glibc 2.17）」glibc 说两遍 | 13 第一遍 | `tierLabel` 只回「旧档 / 常规档」 |
| P1 | 表单字段不成网格（列宽随手分）、开关像端口的附属、表单没有自己的取消 | 07 第一遍 | `.oc-form` 两列网格 + 「连接行为」分组 + 底部 [保存][取消] |
| P1 | 配置差异卡是一堵 11px 灰字墙，没有分区、结论埋在计数句后 | 15 第一遍 | 结论行置顶 + 五个 `KitSeparator` 分区 + 「算不出哈希」加解释 |
| P1 | 日志三段只有一行灰标签，连成一片 | 17 第一遍 | 三段各一个带标签的 `KitSeparator` |
| P2 | 移除确认挤进「维护」按钮行，取消被挤出可视区 | 11 第一遍 | 确认独立成块（横幅 + 两按钮一行） |
| P2 | 移除与 日志/编辑 同排同尺寸 | 10 第一遍 | 「移除」单独一组一行 |
| P2 | 未安装的卡没有「详情」，右侧两个折叠按钮位置与别的卡不一致 | 05 第一遍 | 所有卡都显示「详情 ▾」 |

| P2 | 首跑的人不知道装完还有一步配对 | 09 第一遍 | 已装未启动时加一行「已装好。下一步：启动 → 创建配对链接」 |

## 已知的 P3（记录，不修）

- 「更多」里的组标签（配置/维护/开关/移除）与组内按钮左边缘差一个按钮内边距，读起来像子级缩进——有意为之，但缩进量由宿主按钮 padding 决定。
- 差异分区的计数行仍是一句全角分隔的 run-on；分区标题已经在上面，可读性够。
- 卡片级错误横幅排在版本行与状态详情行之间；位置够显眼，暂不调整。

## 测不到的（要真机）

宿主里真实的面板宽度、hover / focus ring、键盘 Tab 顺序、宿主自己的滚动行为——
预览是假宿主，这几项只能你在 app 里点。
