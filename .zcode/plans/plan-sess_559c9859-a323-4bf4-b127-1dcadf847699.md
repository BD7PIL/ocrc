# 0.21.0：移动端 composer 图标化（对齐 ZCode）+ 四项修复

## 1. 移动端 composer 图标工具条（ZCode register，核心改动）
- **≤820px**：composer 底行从"长文字 chips"改为图标组——
  attach(照旧) | agent 图标(cpu，点开 AgentChip 现有弹层) | 模型图标(bolt，点开 ModelChip 现有弹层) | **上下文环图标**(点开 ContextRing 细分面板) | spacer | 发送/停止。
- 实现：AgentChip/ModelChip 加 `iconOnly` prop（移动端只渲染图标按钮，弹层不变）；ContextRing 加 `compact` 移动实例挂 composer（桌面仍显示环+百分比于同位置）。
- 弹层适配：agent/model/context 弹层移动端宽 min(86vw)，向上弹出（composer 内）不变。
- 桌面端 composer 不动（chips 文字版保留——桌面空间够，信息量大更好）。

## 2. chips 时机修复（你抓的 bug）
- +page.svelte 的 suggestions 门槛加 `feed 已加载`：loading 三点期间**不显示** STARTERS；仅 feed 到位且 cards 为空的新会话显示。

## 3. 主题三态（light → dark → auto）
- ui.ts toggleTheme 循环三档：light/dark/**auto**（auto = 移除 data-theme 覆盖，跟随 prefers-color-scheme）；localStorage 存 'auto'。
- app.html 早脚本同步：t==='auto' → 不设属性（即跟随系统）。
- 图标三态：light=sun、dark=moon、auto=monitor（显示器，画一个新 svg）；RailFoot 与 Titlebar 移动端钮共用（两处都渲染同一逻辑，抽 ThemeIcon 小组件或复制 svg）。

## 4. 移动端会话行 ⋯ 消失修复（上轮 CSS 顺序 bug）
- SessionList：桌面兜底 `.act.mmore,.rowmenu{display:none}` 从媒体块**后**移到**前**（0.16.3 PlanHud 同款教训：形态切换规则必须先声明基础态）。

## 5. 验证与发布
- CDP 390px：chips 加载中不闪现；composer 五图标齐全+三弹层可用；⋯ 按钮出现；主题钮三态循环生效（auto 档跟随系统）；标题行、输入框不回归。
- CDP 1600px：桌面 composer 原样、RailFoot 主题钮三态、mmore 隐藏。
- 全套测试绿 → **0.21.0**（交互模式改动，升 minor）→ 生产升级 → 移动端复验。
