# 右栏对齐 ZCode：动态开页签系统（0.17.1）

## 模型（照 ZCode `workspaceSidePane.ts` 的机制，非照抄它的页签集合）
- **基础页签（pinned，不可关）**：任务 / 文件 / 子代理 / Skills / 配置——我们的远控场景自有面板。
- **动态页签（按需开、可关、持久化）**：
  - `sub:<childId>` 子代理会话实况——在子代理列表点击后**开页签**（不再内嵌置换）；
  - `file:<path>` 文件查看器——在文件列表点击文件后**开页签**（不再双栏/整栏置换）。
- **结构化 id 幂等复用**（ZCode activateSidePaneTab 语义）：同一子会话/文件重复点击=激活已有页签，不开重复页；上限 12 页，超出丢最旧。
- 状态 `{ tabs[], activeId }` 持久化 localStorage `ocrc.sidePane.v1`；关页签激活邻居（前→后→回退基础页），activeId 永不悬空。基础页签与动态页签共用 activeId 命名空间。
