# P2b 执行计划 v3：TG grammY 化 + grinev UX 移植 + 跨通道定时任务

## 已裁决（累计）
- 渲染管线全量移植（blocks + 编辑/富草稿 + 渐进节流 + 三段降级）；富消息不可用自动降级
- i18n 默认中文；回复键盘采纳
- 排除：TTS/STT（需单独 LLM 凭证）、服务模式（B2 结构性不适用）；better-sqlite3 依赖不移植、功能落 bun:sqlite/node:sqlite 双回退
- **定时任务升级为跨通道功能**：调度引擎进 core，TG 与 web 为双前端（用户提出，构成 P2c 严格对齐约束的第二次已批功能增补）

## 架构原则
1. grammY 原地替换 telegraf；Transport 接口不变，宿主接线零改动
2. 单一事件源：SummaryAggregator 契约由 relay 规范化事件重喂，TG 消费 cardBus；question.asked 补 question 卡（适配器级）
3. grinev managers 直接移植，保留"managers 不碰 Telegram/opencode"分层
4. 会话 pin/current/覆盖沿用 SessionState（与 web 共享）；交互互斥槽 TG 域私有
5. 设置落 ~/.ocrc/telegram-settings.json；**排程落 ~/.ocrc/schedules.json**（原子写+重启重臂）
6. 白名单保留；交互槽全局单槽
