# 0.20.3：移动端会话行操作收敛（⋯ 菜单）+ focus 描边修复

## 1. 移动端操作列收敛为一个 "⋯"（你圈的空间问题）
- **桌面（hover 可用）不动**：三按钮 hover 淡入的现状保留。
- **移动端**（`@media (hover: none), (max-width: 820px)`）：三个 40×40 常驻按钮替换为**单个 "⋯" 按钮**（40×40，触控目标不减），点击弹出行内菜单（复用 PlanHud 的局部菜单模式：局部 state + stopPropagation + outside-pointerdown 关闭 + Escape）：
  - 菜单项：重命名 / 置顶（或取消置顶，随状态）/ 删除（保留现有两步武装删除语义）；
  - 菜单从行内弹出，宽度 ~150px，z-popover；
  - 释放约 84px 横向空间给标题。
- 删除流程从菜单触发后仍走既有的两步确认，不改语义。

## 2. 方形 focus 描边修复（你上一问）
- 全局（theme.css）给 `button:focus` 去默认 outline、`button:focus-visible` 保留 2px outline 但 `outline-offset` + `border-radius: inherit`（键盘无障碍保留，鼠标/触摸点击不再出现方形框）。
- 发送/停止圆钮、FAB 等圆形按钮描边随圆。

## 3. 验证
- CDP 390px：行内只见一个 ⋯；点开菜单三项可用（置顶/删除走真实 API mock 页面交互验证）；标题不再被挤压。
- CDP 桌面 1600px：hover 三按钮行为不变。
- focus 描边：点击发送按钮后无方形框，Tab 键盘导航仍可见 focus ring。
- SessionList 测试（现有断言不锁按钮）+ 全套绿。
