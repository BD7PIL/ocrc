# 动效补齐：五条缺口一次落地（纯 web，无插件改动）

## 已核实的实现口径

- theme.css 已有共享动效令牌：`ocrc-rise`(8px+fade)/`ocrc-pop`(scale)/`ocrc-fade`(opacity) + `--ease-out`/`--dur-enter: 200ms`。新增一个 `ocrc-rise-sm`（4px 上浮，给 load-earlier 这类小控件）。
- FilesPanel 的动画只在预览模态上（ocrc-pop .16s），Inspector 列表全线无入场——Skills/Worktrees 直接加"首次到达 fade"（`{#if rows.length > 0}` 分支挂载时播一次 ocrc-fade 150ms，"none" 空态保持静态，符合规则 6 非动效冗余）。
- `.jump` 有 `translateX(-50%)` 定位，入场动画不能用会顶掉它的 transform——用 ocrc-fade（纯 opacity）；`.load-earlier` 无 transform 冲突，用 ocrc-rise-sm。

## 改动清单（全部 web/src，约 8 个文件）

1. **theme.css**：新增 `@keyframes ocrc-rise-sm`（translateY(4px)+opacity，160ms 用法自选）。
2. **+page.svelte**：
   - `.jump` 加 `animation: ocrc-fade 150ms var(--ease-out) backwards`；
   - `.load-earlier` 加 `animation: ocrc-rise-sm 160ms var(--ease-out) backwards`；
   - `.stream` 挂 `class:suppressed={$feedResyncing}`，CSS 加 `.stream.suppressed > :global(*):last-child { animation: none }`（第 5 条重同步抑制）。
3. **ui.ts**：新增 `feedResyncing = writable(false)`。
4. **+layout.svelte**：`resyncViaRest` 里 setHistory 前置位、350ms 后复位（覆盖 --dur-enter 200ms + 余量）。
5. **CardQuestion.svelte + CardApproval.svelte**（一致性成对改）：resolved 行挂 `class:fresh`，仅本地操作触发的换装（done !== ''）才有 `animation: ocrc-fade 150ms`；外部 resolved 回推（card.resolved 到达）不播——遵守规则 1"历史/回放即即时"。
6. **OfflineBanner.svelte**：挂载时 `banner-drop 180ms`（translateY(-100%)→0 + 组件内 keyframe），断线/重连条滑入，消失保持瞬时。
7. **SkillsPanel/WorktreesPanel**：列表块挂载时 `ocrc-fade 150ms`（`{#if rows.length>0}` 分支天然只在首次到达时挂载）。

## 测试与验证

- CardQuestion.test.ts 补两个断言：本地取消后 resolved 行含 `fresh`；外部 republish 的 resolved 行**无** `fresh`（防回归规则 1）。
- 验证：`svelte-check` 0 错误 → web vitest 全绿 → web build 成功 → commit。
- 不动插件侧，不重启实例（纯前端静态资源，下次重启自然生效；如需立即看效果可单独重启一次 spike）。

## 明确不做（维持裁决）

- TG 侧不引入动效；滚动锚定不加 smooth；退场动画一律瞬时（防拖沓）。
